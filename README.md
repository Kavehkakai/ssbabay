# ssbabay — جشن کوچولوی سارا و سعید 💙💖

وب‌اپ فارسی و راست‌چین برای جشن بیبی‌شاور/تعیین جنسیت؛ مهمان‌ها با مرورگر موبایل وارد می‌شوند و نیازی به نصب اپ نیست.

## امکانات
- رأی تیم پسر/دختر، حدس وزن و روز تولد و پیشنهاد اسم
- نمودار درصد آرا و صفحهٔ نمایشگر مناسب تلویزیون
- مسابقهٔ ۱۰ سؤالی «مامان یا بابا؟» با جدول امتیازها
- دفتر یادگاری و دانلود نسخهٔ HTML قابل چاپ/ذخیره به PDF
- رابط واکنش‌گرا با تم ملایم صورتی و آبی

## اجرای محلی
```bash
npm install
npm run dev
```

## همگام‌سازی زنده بین گوشی‌ها
بدون Supabase، داده‌ها فقط در همان مرورگر ذخیره می‌شوند. برای رأی‌گیری مشترک در چند دستگاه:

1. در [Supabase](https://supabase.com/) یک پروژه بساز.
2. محتوای `supabase/schema.sql` را در SQL Editor اجرا کن.
3. فایل `.env.example` را به `.env.local` کپی کن و `VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY` را از تنظیمات پروژه وارد کن.
4. `npm install` و سپس `npm run build` را اجرا کن و روی Vercel یا میزبان استاتیک منتشر کن.

**امنیت:** سیاست‌های SQL نمونه برای یک رویداد عمومی و کم‌حساسیت هستند؛ همه می‌توانند رأی‌ها و پیام‌ها را بخوانند و ورودی ثبت کنند. برای رویداد خصوصی، کنترل دسترسی و محدودسازی اسپم اضافه کن. کلید service-role را هرگز در کد مرورگر قرار نده.
